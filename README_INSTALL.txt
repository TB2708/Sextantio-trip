OUR PLACES — ANNIVERSARY EDITION 3.1

PURPOSE
This release adds a presentation-ready Gift Mode while keeping the private planning and backup tools available separately.

NEW IN VERSION 3.1
- Dedicated anniversary Gift Mode
- Personal dedication page
- Santo Stefano presented as Volume I
- Cleaner book-style journey presentation
- Planner controls hidden in Gift Mode
- Return to Planner button
- Improved iPad presentation
- Existing photo, trip library, backup and restore features retained

UPDATE YOUR EXISTING GITHUB SITE
1. Extract this ZIP.
2. Open your GitHub repository: Sextantio-trip.
3. Choose Add file → Upload files.
4. Upload every file from this package.
5. Allow GitHub to replace the existing files.
6. Commit changes.
7. Wait approximately 1–3 minutes for GitHub Pages to redeploy.
8. Open the published address in Safari and refresh.
9. Close and reopen the Home Screen app.

USING GIFT MODE
- Tap Open gift mode in the header.
- Planner, gallery, backup and editing controls are hidden.
- The app opens as a romantic book-style presentation.
- Tap Return to planner on the dedication screen to restore the private tools.

IMPORTANT
Gift Mode is a presentation layer, not a password lock. It hides planning controls from casual view but is not intended to protect highly sensitive information.

DATA
Existing locally stored trips and photographs remain on the device because this update keeps the same IndexedDB database.
Continue exporting backups regularly.
